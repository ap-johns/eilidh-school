---
description: Ensure a scanned PDF is A4 page size before submitting
argument-hint: <path-to-pdf>
allowed-tools: Bash(pdfinfo:*), Bash(.claude/scripts/to-a4.sh:*), Read
---

Ensure the PDF at `$1` is A4 page size before it gets submitted.

Do this:

1. Run `pdfinfo "$1"` and read the reported **Page size** (and page count). A4 is
   `595.28 x 841.89 pts` — pdfinfo labels known sizes, e.g. `(A4)` or `(letter)`.
   For a multi-page file, also spot-check the last page with
   `pdfinfo -f <N> -l <N> "$1"` where N is the page count.

2. If every page is already A4, tell the user it's good to submit — do nothing else.

3. Otherwise run `.claude/scripts/to-a4.sh "$1"` to produce `<name>-a4.pdf`. Each page
   is scaled to fit A4 with aspect ratio preserved (no stretching or cropping).

4. Verify the result with `pdfinfo` on the new file, then report to the user:
   the original size, the new file path, and confirm it is now A4.

If the argument is missing, ask the user for the path to the scanned PDF.
